# Sơ đồ

Sơ đồ UML vẽ bằng draw.io. Mỗi sơ đồ lưu 2 file: file nguồn `.drawio` để chỉnh sửa và ảnh `.png` để hiển thị trong tài liệu và báo cáo.

| Sơ đồ | Ảnh | File nguồn | Dùng trong |
|---|---|---|---|
| Use case tổng quát và phân rã mua hàng | [use-case.png](use-case.png) | [use-case.drawio](use-case.drawio) | [SRS](../01-srs/README.md) |

Sơ đồ ERD không lưu ở đây: được viết bằng Mermaid ngay trong [02-database](../02-database/README.md), GitHub tự vẽ.

Quy ước đặt tên: chữ thường, không dấu, nối bằng gạch ngang, ví dụ `use-case.png`, `sequence-dat-hang.png`.
